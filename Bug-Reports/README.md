# ParaBank – Bug Reports

## Purpose

This folder contains documented defects identified during manual testing of the ParaBank online banking application.

## Bug Reporting Information

Each confirmed defect report will include:

- Bug ID
- Bug Title
- Application Module
- Environment
- Preconditions
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Evidence
- Defect Status

## Testing Approach

Only genuine defects reproduced during testing will be documented.

Hypothetical defects will not be presented as actual findings.
