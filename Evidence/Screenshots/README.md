# ParaBank – Testing Evidence

## Purpose

This folder contains screenshots captured during manual testing of the ParaBank online banking application.

## Evidence Naming Convention

Screenshots will be named according to their corresponding test case IDs.

Examples:

- TC001.png
- TC002.png
- TC003.png

## Evidence Requirements

Screenshots will be captured to support actual test execution results and confirmed defects.
