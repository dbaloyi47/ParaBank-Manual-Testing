ParaBank Manual Testing Project

1. Project Overview

This project demonstrates practical manual software testing of the ParaBank online banking application.

The objective is to evaluate banking application functionality, identify defects, document test results and demonstrate practical software testing techniques.

2. Application Under Test

- Application: ParaBank
- Website: https://parabank.parasoft.com/parabank/index.htm
- Testing Type: Manual Testing
- Testing Approach: Black-box Testing
- Testing Level: System Testing
- Testing Focus: Functional Testing

3. Testing Scope

The following application functionalities are included in the testing scope:

- User Registration
- User Login and Logout
- Account Overview
- Account Details
- Fund Transfers
- Bill Payments
- Account Services
- Transaction History
- Input Validation
- Error Handling

4. Testing Techniques

The following testing techniques will be applied:

- Equivalence Partitioning
- Boundary Value Analysis
- Decision Table Testing
- Error Guessing
- Exploratory Testing
- Positive and Negative Testing

5. Testing Activities

The project includes the following software testing activities:

- Reviewing application requirements and functionality.
- Preparing test scenarios and test cases.
- Preparing test data.
- Executing manual test cases.
- Recording actual and expected results.
- Identifying and documenting defects.
- Capturing screenshots as testing evidence.
- Performing confirmation testing and regression testing.
- Preparing test execution reports.
