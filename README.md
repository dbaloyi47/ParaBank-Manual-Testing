# ParaBank Manual Testing

**Manual Software Testing Portfolio – Online Banking Application**

## Project Overview
This project demonstrates manual software testing of the ParaBank online banking demo application. The purpose is to evaluate the application's functionality, identify defects, and document test results using structured testing techniques.

## Testing Objectives
- Verify user registration and login functionality.
- Test account overview and account opening.
- Test fund transfers between accounts.
- Test online bill payments.
- Verify transaction history.
- Test customer profile updates.
- Verify logout and session management.

## Testing Scope
- Functional Testing
- Positive and Negative Testing
- UI Testing
- Regression Testing
- Confirmation Testing
- Boundary Value Testing (where applicable)

## Tools and Technologies
- Microsoft Excel – Test case documentation and execution tracking.
- GitHub – Test documentation and portfolio management.
- ParaBank Demo Application – Application under test.

## Project Structure
- `Test-Plan/` – Test plan and testing approach.
- `Test-Scenarios/` – High-level test scenarios.
- `Test-Cases/` – Detailed test cases.
- `Test-Data/` – Test data documentation.
- `Bug-Reports/` – Defect documentation.
- `Test-Execution/` – Test execution report.
- `Evidence/Screenshots/` – Testing screenshots and evidence.

## Application Under Test
[ParaBank Demo Application](https://parabank.parasoft.com/parabank/index.htm)

*Note: ParaBank is a demonstration banking application. No real banking or personal financial information is used.*
