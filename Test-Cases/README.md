# ParaBank – Test Cases

## Purpose

This folder contains detailed manual test cases designed to verify the functionality of the ParaBank online banking application.

## Test Case Documentation

Each test case will include:

- Test Case ID
- Test Scenario
- Test Description
- Preconditions
- Test Steps
- Test Data
- Expected Result
- Actual Result
- Execution Status
- Evidence

## Testing Approach

Both positive and negative testing techniques will be applied.

Test cases will cover registration, authentication, account management, fund transfers, bill payments and transaction history.

Test case preparation in progress.
