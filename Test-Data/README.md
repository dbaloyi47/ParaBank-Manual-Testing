# ParaBank – Test Data

## Purpose

This folder contains the test data required to execute manual test cases for the ParaBank online banking application.

## Test Data Categories

- Customer registration information.
- Valid and invalid login credentials.
- Account information.
- Fund transfer amounts.
- Bill payment information.
- Customer profile information.

## Data Management

Only fictional test data will be used.

No real banking credentials, personal financial information or payment details will be used.

Test data preparation in progress.
