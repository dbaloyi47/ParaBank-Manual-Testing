# ParaBank – Manual Testing Test Plan

## 1. Project Overview

**Project Name:** ParaBank Manual Testing  
**Application:** ParaBank Online Banking Demo  
**Testing Type:** Manual Software Testing  
**Testing Approach:** Functional Testing

## 2. Testing Objectives

The objective of this project is to evaluate the functionality, reliability and usability of the ParaBank online banking application.

## 3. Scope of Testing

The following modules will be tested:

- User Registration
- User Login
- Account Overview
- New Account Opening
- Fund Transfers
- Bill Payments
- Transaction History
- Customer Profile Management
- Logout and Session Management

## 4. Testing Types

- Functional Testing
- Positive Testing
- Negative Testing
- Boundary Value Testing
- Regression Testing
- UI Testing

## 5. Testing Environment

| Item | Details |
|---|---|
| Application | ParaBank |
| Browser | To be confirmed |
| Operating System | To be confirmed |
| Testing Method | Manual |
| Test Management | Microsoft Excel |
| Documentation | GitHub |

## 6. Entry Criteria

- Application is accessible.
- Test environment is available.
- Test scenarios and test cases are prepared.

## 7. Exit Criteria

- Planned test cases have been executed.
- Results have been documented.
- Confirmed defects have been reported.
- Test execution report has been completed.

## 8. Defect Management

All confirmed defects will be documented with reproduction steps, expected results, actual results, severity, priority and supporting evidence.
