# ParaBank – Test Scenarios

## 1. Introduction

This document contains the test scenarios identified for the ParaBank online banking application.

## 2. Test Scenarios

| Scenario ID | Module | Test Scenario |
|---|---|---|
| TS001 | Registration | Verify that a new customer can register successfully. |
| TS002 | Registration | Verify registration with mandatory fields left blank. |
| TS003 | Login | Verify login with valid credentials. |
| TS004 | Login | Verify login with an incorrect password. |
| TS005 | Login | Verify login with an invalid username. |
| TS006 | Account Overview | Verify that customer accounts are displayed. |
| TS007 | Account Overview | Verify account balances are displayed. |
| TS008 | Account Opening | Verify that a customer can open a new account. |
| TS009 | Account Opening | Verify account opening with different account types. |
| TS010 | Fund Transfer | Verify successful transfer between accounts. |
| TS011 | Fund Transfer | Verify transfer using an invalid amount. |
| TS012 | Fund Transfer | Verify transfer between different account types. |
| TS013 | Bill Payment | Verify successful bill payment. |
| TS014 | Bill Payment | Verify bill payment with missing information. |
| TS015 | Transactions | Verify transaction history is displayed. |
| TS016 | Transactions | Verify transaction search functionality. |
| TS017 | Customer Profile | Verify customer profile information. |
| TS018 | Customer Profile | Verify updating customer information. |
| TS019 | Logout | Verify successful logout. |
| TS020 | Session Management | Verify behaviour after logout. |
